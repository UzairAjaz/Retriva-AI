# Retriva React Chat UI

Simple premium chatbot UI built with React + Tailwind.

Features:
- New Chat
- Chat history + search
- Hover three-dot menu
- Rename/Delete chat
- User messages on RIGHT
- Retriva responses on LEFT
- Source chips
- Loading state
- Responsive mobile sidebar
- Demo response ready to replace with FastAPI

Run:
```bash
npm install
npm run dev
```

The current `send()` function uses a demo timeout. Replace it with a POST request to your FastAPI endpoint when the backend is ready.
